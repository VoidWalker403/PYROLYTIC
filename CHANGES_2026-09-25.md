## Files and behavior changed

### `discover_papers.py` — new

- Queries the public Crossref REST API across eight plastic-pyrolysis topics.
- Limits results per query, applies a publication-date cutoff, and requires
  both pyrolysis and plastics/polymer terms in titles.
- Excludes obvious correction/retraction notices, records updating other works,
  and a news publication; this is not a comprehensive quality/retraction audit.
- Normalizes DOI case, deduplicates across queries, records authors/year/journal,
  and derives topic/review labels from title keywords.
- Retains metadata URLs, query provenance and retrieval times.
- Uses three bounded request attempts with 30-second timeouts and backoff.
- Replaces the snapshot atomically only after all topic requests succeed.
- Optional `--import-library` merges the snapshot into SQLite without altering
  experimental values or saved curation decisions.

### `research_library.json` — new

- Public, portable snapshot of 582 DOI records collected through September 25,
  2026, spanning publication years 1945–2026.
- Contains bibliographic metadata and provenance, not private notes or full texts.
- Search selection is relevance-based and non-exhaustive, not a systematic review.
- Source: [Crossref REST API](https://www.crossref.org/documentation/retrieve-metadata/rest-api/).

### `research_library.py` — new

- `ensure_library()` creates `research_library` and `library_snapshots` tables and
  idempotently merges bundled metadata plus existing experiment sources.
- DOI aliases merge within the catalog; original `papers` identifiers stay intact.
- `validate_snapshot()` rejects malformed metadata and duplicate DOI aliases
  before any writes. Refreshes preserve omitted papers and all review fields.
- `query_library()` joins extraction coverage without manufacturing experiments.
- `filter_library()` supports text, status, topic, year, type and coverage filters.
- `save_review()` saves status/notes with optimistic concurrency checking.
- `export_csv()` exports the entire filtered result set, protecting text cells
  against spreadsheet formula interpretation.
- `render()` provides 50-record pages, publisher/metadata links and persistent
  local review forms. Saves immediately refresh tables and export content.
- The catalog loads after login without network requests on dashboard reruns.

### `app.py`

- Initializes the library after the authentication gate, displays its count
  separately from extracted source counts, and renders its curation interface.
- Replaces unsupported model scores, missing report references and static route
  ranking claims with workflow explanations that state the project's limits.
- Labels Demo Mode as static examples.
- Shows recovery guidance for live-pipeline failures; logs only the exception
  class, without raw error text, source content or prompts.

### `literature_browser.py`

- Avoids `min()`/`max()` calls on empty temperature collections.
- Shows a caption for constant temperature values instead of an invalid slider.
- Uses floating-point bounds so fractional temperatures are not rounded out of
  the initial range. Missing temperatures remain visible.

## Using the expanded library

Start the app normally, sign in, and use **Research paper library**. Filter
**Awaiting extraction** to inspect new candidates; shortlist useful studies and
record your review notes. Open the DOI link to check access and the original
paper. Verify values, units and page/table provenance before importing experiments.

Refresh example:

```powershell
.\.venv\Scripts\python.exe discover_papers.py --rows 100 --import-library
```

Future work remains: source-verified measurement extraction, permitted full-text
acquisition, systematic quality/retraction checks, and reproducible model training.
The chat index continues to contain extracted experiments and local texts;
bibliographic titles alone are not used as evidence for numerical answers.
